# 🔧 Backend — Setup & Environment

> Everything you need to clone, configure, and run the NoteDown backend locally.

---

## 📋 Prerequisites

| Requirement | Minimum | Notes |
|---|---|---|
| Node.js | v18+ | v20 LTS recommended |
| npm | v9+ | Comes with Node |
| MongoDB | Atlas (cloud) | Local Mongo works too, but Atlas is needed for Vector Search |
| AWS Account | — | For S3 bucket |
| VirusTotal Account | — | Free API key |
| Resend Account | — | Free tier: 3000 emails/month |
| Google AI Studio | — | For Gemini API key(s) |

---

## ⚡ Quick Start

```bash
# 1. Clone and navigate to backend
git clone https://github.com/UsaaryanByte07/NoteDown.git
cd NoteDown/backend

# 2. Install dependencies
npm install

# 3. Create your .env file (see below)
cp .env.example .env   # or create manually

# 4. Start development server (nodemon)
npm run dev
# → Server starts at http://localhost:3010
# → AdminJS panel at http://localhost:3010/root/panel
```

> **Scripts**
> | Command | Description |
> |---|---|
> | `npm run dev` | Start with nodemon (auto-reload) |
> | `npm start` | Start with node (production) |

## 🪣 AWS S3 Bucket Setup

1. Create a bucket in your chosen region
2. **Block all public access** — files are stored privately, no public URLs
3. Set a bucket policy to allow your IAM user `s3:GetObject`, `s3:PutObject`, `s3:DeleteObject`
4. Generate IAM access keys with `AmazonS3FullAccess` (or a scoped policy) and put them in `.env`

> Files are served to users via **pre-signed URLs** generated by the backend, not via public bucket access.

1. Go to [Google AI Studio](https://aistudio.google.com)
2. Create an API key in your project
3. The backend supports up to **4 keys** with automatic failover — useful for free tier rate limits
4. Used for: AI summaries on note approval + vector embeddings for chat

## 🗂️ MongoDB Atlas Setup

1. Create a free M0 cluster at [mongodb.com/atlas](https://www.mongodb.com/atlas)
2. Create a database named `notedown`
3. Allow your IP (or `0.0.0.0/0` for development) in Network Access
4. **Create a Vector Search Index** on the `note_embeddings` collection:
   ```json
   {
     "fields": [
       {
         "type": "vector",
         "path": "embedding",
         "numDimensions": 768,
         "similarity": "cosine"
       },
       {
         "type": "filter",
         "path": "noteId"
       }
     ]
   }
   ```
   Name the index exactly: `vector_index`

> ⚠️ Without the vector index, the chat feature will fail with Atlas errors. The rest of the app works fine without it.

## 🔄 Creating the First Root System User

The AdminJS panel (`/root/panel`) requires a `SystemUser` with `role: "root"`. Create one manually via the MongoDB shell or Compass:

```js
// Run in MongoDB Shell (mongosh)
use notedown
db.systemusers.insertOne({
  name: "Root Admin",
  username: "root",
  password: "<bcrypt-hashed-password>",   // hash with bcrypt rounds=10
  role: "root",
  createdAt: new Date(),
  updatedAt: new Date()
})
```

You can hash a password using Node.js:
```bash
node -e "const b=require('bcryptjs'); b.hash('yourpassword',10).then(h=>console.log(h))"
```
